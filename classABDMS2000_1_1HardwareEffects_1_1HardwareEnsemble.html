Descripción detallada

3-Tap BBD String Ensemble extracted from P:$0F96 - $0FE8 (r3 = $0240).

Microcode Reference:

  • Parameter block: X:$0240..$025F, Y:$0320..$032F
  • External DRAM circular buffer: Y:$480000..$480FFF (4096 x 16-bit samples, mask $480FFF at X:$025A)
  • 3-phase slow LFO (0 deg, 120 deg, 240 deg via Y:$0328 = $555555 = 2/3) combined with fast shimmer LFO (P:$0FC7 - $0FD6).
  • Stereo tap mixing matrix (P:$0FAA - $0FB6) using Y:$0329 = $199999 (0.2), Y:$032A = $333333 (0.4), Y:$032B = $666666 (0.8), X:$0251 = $2CCCCC (0.35).
