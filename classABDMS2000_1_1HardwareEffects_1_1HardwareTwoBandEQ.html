Descripción detallada

Stereo cascaded 1st-order Low-Shelf + 1st-order High-Shelf Equalizer extracted from P:$08B0 - $08E7 (r3 = $0011, X:$0016..$001B).

Microcode Reference (P:$08B0 - $08D7):

  • Stage 1 (Low Shelf, P:$08B7 - $08BD Left, P:$08C8 - $08CD Right): y1[n] = sat24(4.0 * (b0_low * x[n] + b1_low * x[n-1] + a1_low * y1[n-1])) Default flat coefficients in X:$0016..$0018: b0_low = $1FFFFE (+0.25), b1_low = $F76CF6 (-0.066987), a1_low = $08930A (+0.066987)
  • Stage 2 (High Shelf, P:$08BE - $08C7 Left, P:$08CE - $08D7 Right): y2[n] = sat24(4.0 * (b0_high * y1[n] + b1_high * y1[n-1] + a1_high * y2[n-1])) Default flat coefficients in X:$0019..$001B: b0_high = $400000 (+0.50), b1_high = $C40EB5 (-0.468301), a1_high = $3BF14B (+0.468301)
