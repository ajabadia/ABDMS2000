Descripción detallada

Korg MS2000 / MS2000R Hardware Firmware Updater & 1 MB Flash Backup ("IPL") Protocol.

Implements the host-side IPL SysEx protocol (F0 42 23 58 <cmd> ... F7) dissected from:

  • Korg MS2000 v1.07 IPL ROM (H8S/2350 @ 0x4070F0, flash offset 0x000D54..0x001DD6)
  • Korg Windows System Update Utility vup_ms2000.exe v1.3
  • unknown-technologies fwpatch / fwdump (IPL Command 0x01 Flash Dump at RAM 0x408084)

Strictly for Korg MS2000 and MS2000R (original DSP56362 + H8S/2350 hardware). NEVER use with MS2000B / MS2000BR (different hardware/firmware).

◆ makeDumpSys()

bool ABDMS2000::ms2kipl::makeDumpSys ( const Bytes & v107,
Bytes & out,
std::string & err )

Builds the flash-dump-enabled v1.07 system image from official x811v107.sys: injects the 366-byte H8S/2350 dump routine at file 0x1DD8 (RAM 0x408084), updates IPL copy count at 0x1CCE, hooks cmd_table[1] at 0x1CE0, and rebalances the 16-bit big-endian word checksum at 0x1FFE so the 256 KB sum remains 0x0000.
