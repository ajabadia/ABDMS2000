15enum class SysExMessageType {
16 Unknown = 0,
17 ProgramDump, // 0x40: 1 Program Data Dump
18 AllDataDump, // 0x4C: All Data Dump (128 Programs)
19 ParameterChange, // 0x41: 1-Parameter Change
20 ProgramDumpRequest, // 0x10
21 AllDataDumpRequest, // 0x0E
22 WriteCompleted, // 0x23: el otro extremo guardó lo que le mandamos (ACK)
23 WriteError // 0x24: el otro extremo no pudo guardarlo (NACK)
24};

34 /**
35 * Bytes que hay que devolver por el cable por haber recibido este mensaje
36 * (vacío si no toca contestar nada):
37 * - el volcado que responde a una petición `0x10`/`0x0E`;
38 * - el acuse `0x23`/`0x24` de una escritura `0x40`/`0x4C` (guardada o no).
39 * El transporte MIDI lo manda tal cual; al importar un archivo se ignora.

51 /**
52 * Parses raw SysEx bytes (from .syx file or MIDI input).
53 *
54 * Peticiones reconocidas: `F0 7D 0A 10/0E F7` (ABDSynths) y
55 * `F0 42 3n 58 10/0E F7` (Korg) → `ProgramDumpRequest` / `AllDataDumpRequest`
56 * con `midiChannel` del canal pedido. La respuesta se construye con
57 * `buildProgramDumpResponse` / `buildAllDataDumpResponse`.
58 *
59 * Escrituras (`0x40`/`0x4C`) de ambas familias: además de guardarlas, el
60 * resultado lleva en `reply` el acuse que hay que devolver — `0x23` Write
61 * Completed si se guardó, `0x24` Write Error si no. Los acuses **recibidos**
62 * (`0x23`/`0x24`) se reconocen (`WriteCompleted` / `WriteError`) y no se contestan.
63 */

81 /**
82 * Respuesta a una `AllDataDumpRequest` **de Korg** (`F0 42 3n 58 0E F7`): la memoria

84 *
85 * 1. Si llegó memoria del equipo (algún All Data Dump `0x4C`), sale **esa** — bytes

87 * desde el motor** para que el volcado refleje lo que se está oyendo.
88 * 2. Si nunca llegó, el plugin hace de equipo con **su propia memoria**: convierte sus
89 * 128 presets nativos a programas reales de 254 B (`MS2000HardwareProgram::
90 * fromNativeProgram`, conversión aproximada y declarada como tal — lo que el motor
91 * no modela sale del INIT Program del equipo). Ver §6.4 de
92 * `DOCS/ABDSynths_SysEx_Spec.md`; falta verificarlo contra hardware real.
93 */

148 //
149 // El plugin tiene dos formatos y no se mezclan:
150 // - `MS2000ProgramData` (384 B, v2): el preset **propio** del plugin, el sistema
151 // `native` que lee y escribe el ABD Bank Manager embebido. Cabe Timbre 1,
152 // Timbre 2, velocidades, escala/split y los pasos del mod sequence.
153 // - `MS2000HardwareProgram` (254 B): el programa **real** de un MS2000, el que
154 // entra por MIDI desde el equipo y el que se le devuelve.
155 //
156 // Una trama `0x40` de 254 B está escrita en el formato del hardware y se aplica
